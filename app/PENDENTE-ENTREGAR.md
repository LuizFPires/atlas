# App desktop (Electron) — pendências para /entregar

O CI (ubuntu) só roda eslint, tsc, vitest e o build do front. `electron` e `electron-builder` NÃO são dependências do projeto (mantém o `npm ci` leve); `app/` (main.cjs, preload.cjs, cofre.cjs) não é compilado nem linta no CI. A API do Electron fica atrás de `src/app/ponte.ts` (interface testável).

- **Cofre real (Windows Credential Manager / DPAPI).** `app/cofre.cjs` só tem o cofre em memória e falha fechado sem `ATLAS_COFRE=fixture`. Falta o adaptador nativo (ex.: `@napi-rs/keyring` ou `keytar`) implementando `guardar/ler/apagar` para a chave `atlas/dispositivo`. O token do dispositivo NUNCA pode ir para arquivo, localStorage ou log. Sem ele, o app pede ativação a cada abertura.
- **Empacotar e assinar.** `npm run build:app` gera `dist-app/` (caminhos relativos, sem PWA). Falta empacotar `app/` + `dist-app/` como `Atlas.exe` (electron-builder, versão exata), assinar (Azure Trusted Signing, ver `instalador/PENDENTE-ENTREGAR.md`) e testar em Windows limpo. O instalador (M8) já chama `Atlas.exe --tela=F02`.
- **Token do link de instalação.** `/ativar/confirmar` exige o token de uso único do link (~48 h). O app lê `--token=...` da linha de comando; o instalador (M8) ainda precisa repassar esse valor ao abrir o app (hoje só passa `--tela=F02`). Sem token a tela avisa com um recado amigo.
- **Reconhecimento de voz no Electron.** O `SpeechRecognition` do Chromium dentro do Electron não funciona sem chaves do Google. Para "tudo pode ser falado" valer no app é preciso um motor de transcrição (ex.: Whisper local ou serviço do Atlas). A interface (`useVoz`) já isola isso; no navegador funciona.
- **Progresso da instalação.** `Ativacao` aceita `progresso` (percentual/restante); falta o instalador (M8) publicar o andamento real para o app.
- **Ids reais do plugin e PLUGIN_SHA256** (`instalador/passos.ts`): seguem placeholder (empacotamento do kit como plugin fica para o M26); o instalador falha fechado.
- **Bloqueio de sono na obra.** `useImpedirSono` está ligado durante a instalação; o M-da-obra deve chamá-lo enquanto houver obra rodando.

- **Defesas OBRIGATÓRIAS do descompactar** (lista completa no topo de `ponte-importar.ts`; o adaptador real precisa de teste de contrato com um .zip malicioso para cada uma):
  1. **Zip-slip / path traversal**: o destino é calculado por nós (`validarPacote` + `caminhoNoPrototipo`), nunca o nome da entrada. Recusar `..`, caminho absoluto (`/x`, `C:\x`, `\srv`), barra invertida, `:` (ADS), controle, nome terminado em ponto/espaço. Conferir com `path.resolve(destino)` que começa com `path.resolve(<raiz>\<obra>\prototipo) + path.sep`.
  2. **Symlink/hardlink/junction**: recusar entrada com modo Unix de link (`0o120000`) e hardlinks; `lstat` em cada pasta do caminho de destino; gravar com flag `wx` (nunca sobrescreve).
  3. **Zip-bomb**: limites em `LIMITES` (.zip 50 MB, 300 entradas, 100 MB descompactado no total, 20 MB por arquivo, razão máx. 100:1 a partir de 1 MB, 3 níveis de pasta). Conferir o cabeçalho E contar os bytes realmente descompactados durante a gravação (cabeçalho mente); estourou, interrompe, apaga só o que gravou nesta tentativa e recusa o pacote todo. Sem .zip dentro de .zip. Descompactar em streaming, não em memória.
  4. **Só tipos esperados**: html, css, js, md, png, jpg/jpeg, webp, svg, json. Qualquer outro (exe, bat, ps1, lnk, dll, vbs, hta, zip...) recusa o pacote inteiro. Nunca abrir/executar nada recebido; HTML só em visualização isolada (iframe `sandbox` sem scripts), SVG só como `<img>`, `.js` só guardado (no Windows um `.js` abre no Windows Script Host: não criar atalho nem abrir).
  5. **Nomes seguros**: `nomeArquivoSeguro` em cada arquivo e pasta; colisão com `nomeLivre`; nomes reservados do Windows (CON, NUL, COM1...). Um segundo envio na mesma obra é recusado (`ja-recebido`): sempre obra nova, nada sobrescrito. O app valida o pacote (`validar`) ANTES de criar a subpasta da obra: falha de validação não deixa pasta vazia. `.DS_Store` e `__MACOSX/` do Mac são ignorados em silêncio (`ehLixoDoMac`) e o adaptador real também não os grava.
  6. **Conteúdo é DADO**: o HTML, `design-system.md`, `telas.md` e `regras.md` entram no Claude só por `montarPedidoCompletar` (usa `comoDado`/`blocoDoCliente`/`REGRA_CONTEUDO_CLIENTE` do M14). O HTML nunca é colado no pedido, só os nomes das telas; o Claude lê os arquivos do disco com a regra de não seguir instruções vindas deles, sem permissão de escrever fora da pasta da obra nem de rodar comandos.
  7. **Link do protótipo**: só http/https, sem usuário/senha, sem IP nem `.local` (`normalizarLinkPrototipo`). O app só mostra o link. Se for checar "abre no celular" (o protótipo mostra isso), fazer no main com tempo-limite e sem seguir redirecionamento para endereço interno (SSRF). Se o adaptador CHECAR o link: resolver o DNS e bloquear IP interno/privado/loopback/link-local do resultado (nomes como `x.nip.io` e `foo.localhost` resolvem para 127.0.0.1), conferindo o IP de cada salto de redirecionamento e do endereço realmente conectado. Teste de contrato por ataque: nip.io, *.localhost, redirecionamento 302 para 169.254.169.254 e DNS rebinding.
  8. **Ataques de formato do .zip (cada um com teste de contrato, um .zip malicioso por ataque)**: (a) **zip criptografado** (bit 0 das flags / AES): recusar o pacote; (b) **zip64 / extra fields**: ler tamanhos do zip64 e ignorar/recusar extra fields que mudem nome ou tamanho; (c) **divergência entre cabeçalho local e central directory** (nome, tamanho, método): usar só o central directory e recusar se o local discordar; (d) **entradas duplicadas ou sobrepostas** (overlap bomb: vários arquivos apontando para os mesmos bytes comprimidos): recusar nome repetido e deslocamentos que se sobreponham; (e) **colisão arquivo x pasta depois de sanitizar** (`x.html` e `x.html/`): recusar o pacote.
- **Completar o que falta**: `conferirPacote` aponta (telas, design-system, telas.md, regras.md, imagens, login, link) e `montarPedidoCompletar` monta o pedido; quem chama o Claude para completar no mesmo estilo é o adaptador do M16 (F07). O botão "Abrir no Atlas e ajustar" volta às obras até a F07 existir.
